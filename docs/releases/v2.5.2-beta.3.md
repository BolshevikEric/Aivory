# Aivory v2.5.2-beta.3

Test release covering all three application commits since **v2.5.2-beta.2**. Fixes Generative UI state summaries and malformed markup recovery, generated-file downloads and images, shared conversation exports, and detection of administrator-published desktop beta updates.

## Generative UI Reliability

- Keep immediately following state-dependent Markdown in the same component group as its controls. Progress summaries after closing tabs now update with the corresponding checkboxes instead of displaying literal expressions.
- Preserve ordinary Markdown when no components are emitted. Recover unknown wrappers as readable text and valid preset components without mounting arbitrary HTML containers or executing their attributes.
- Drop unsafe embedded content and SVG handlers. Recover missing or mismatched closing tags, preserve valid siblings, and show escaped source when a component cannot be recovered.
- Preserve literal code examples, escaped expressions, and LaTeX. Expressions containing Markdown or tag strings remain text rather than creating elements.
- Retain content when required tab panels, radio options, or table cells are missing. Preserve empty-table placeholders, merged cells and rows covered by row spans. Keep a visible panel when the number of tabs decreases.
- Disable follow-up actions that reference unavailable state. Keep independent component groups isolated and retain streaming and read-only restrictions.
- Update the built-in component skill and refresh untouched defaults while preserving administrator edits. Legacy structured UI remains a parsing compatibility path; prompts continue to teach canonical component tags.

## Generated Files and Sharing

- Resolve `attachment://` and sandbox output links against the files actually attached to the same message. Support Chinese and URL-encoded filenames, spaces, parentheses, and trailing prose punctuation.
- Render file links and images inside Markdown, preset buttons and links, table cells, cards, and SVG images. Links become usable when artifact metadata arrives after the message text.
- Preserve ordinary URLs and copyable code examples, including code inside Markdown tables, lists, and quotes. Reject unresolved attachment schemes instead of sending unsupported protocols to the browser; missing or ambiguous filenames do not fabricate a download.
- Use share-scoped artifact URLs in public conversations and frozen artifact metadata in static exports. Preserve recovered components and local state summaries in image and PDF export trees.

## Desktop Beta Updates

- Honor the deployment administrator's published release channel. Stable and beta clients can both detect a newer administrator-published beta when a matching OS and architecture installer is available.
- Preserve semantic version ordering: a stable release never downgrades to a prerelease of the same version, and older versions are never offered as updates.
- Apply the same selection rules to manual and automatic checks. Clients continue to read their configured deployment's update manifest without falling back to GitHub.

## Upgrade Notes

- Deploy the updated API and frontend together. No new database migration is required.
- Desktop installers include the updated local frontend and update checker, and retain the saved server address on upgrade.
- Older stable clients, including **2.5.1**, contain the previous beta filter and may report no update when a beta is published. Manually install a desktop package from this release once; updating the server alone cannot replace that installed client logic.
- Administrators must still select the version and matching installers in **Admin > System > Desktop Client**, enable publication, and save. Publishing a GitHub prerelease does not automatically publish it to every deployment's users.
- Download links require a real generated artifact. A filename written by the model without an attached file cannot be downloaded.
- This is a prerelease. The latest stable release remains **v2.5.1**.

Assets and image tags become available as their workflows finish. The sandbox source is unchanged from beta.2, so source-aware updaters can retain an already-current sandbox.

## Validation

The included changes passed 165 focused frontend tests, all 35 desktop logic tests, targeted built-in skill and desktop-update API tests, TypeScript checking, scoped ESLint, and the production frontend build. Browser assertions cover state summaries, tabs, malformed and unknown markup, literal code and math, streaming restrictions, mobile and desktop layouts, delayed artifact metadata, image loading, nested component and SVG URLs, and an actual Chinese-filename download with byte verification. These checks do not claim a full application suite or native installer execution on every operating system.

Release preparation checks version and lockfile consistency and the complete commit range. CI builds the tagged source, verifies desktop bundles and macOS signatures, and publishes release artifacts.
