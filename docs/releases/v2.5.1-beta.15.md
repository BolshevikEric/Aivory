# Aivory v2.5.1-beta.15

Test release adding interactive visual replies, inline questions and forms, conversation image sharing, and composer skill management. It also includes the latest mobile camera and layout improvements and updates the bundled sandbox only when its source changes.

## Interactive Visual Replies

- Expand inline Generative UI with line, area, bar, stacked bar, horizontal bar, pie, donut, and scatter charts, plus heatmaps and gauges. Users can inspect data points, toggle series, and view the underlying data.
- Add responsive cards for news, search results, recommendations, and candidate plans. Rich tables support filtering and text, links, lists, and external images that fit their cells without stretching or cropping.
- Add editable function graphs. Users can add, edit, hide, or remove functions, adjust parameters and ranges, zoom, and inspect coordinates.
- Add configurable calculators with live formula results, checklists, and quizzes. Calculations use a bounded expression parser rather than executing arbitrary JavaScript.
- Add question selectors and common form controls directly inside assistant replies. Submitting answers sends a normal chat follow-up; no separate popup is opened. Support regular, inline-child, and private conversations, with read-only states for shared content.
- Refresh the built-in `generative-ui` instructions to encourage useful, concise visual answers whenever they improve understanding. Include guidance for choosing components without restricting them to a fixed list of scenarios.
- Remove the retired embedded prompt files. Upgrade untouched shipped defaults by fingerprint while preserving administrator-customized skill instructions.

## Composer Skills and Resources

- Add a **Skills** submenu to the composer plus menu to inspect and manage both model-bound defaults and manually selected skills. Keep slash selection and the menu synchronized.
- Allow model defaults to be disabled or restored for the current conversation. Preserve their system-level loading path and filter disabled skills from previous tool-loading exchanges before building a new request.
- Keep manually selected skills at user authority and scoped to the current turn. Selecting a disabled default through `/` enables it for that turn without silently restoring its saved default state for later turns.
- Preserve skill selections across queued turns, withdrawal, regeneration, model fallback, and forks. Scope saved exclusions by account and conversation.
- Move folder upload and knowledge-base selection into the shared plus menu, remove the research and verification subtitles, and soften active-control styling.
- Animate composer height changes when adding skills, resources, or text, while respecting reduced-motion preferences and mobile viewport positioning.
- Update related translations in English, Simplified Chinese, Traditional Chinese, Japanese, and French.

## Share Conversations as Images

- Add **Share as link** and **Share as image** under the conversation share submenu on desktop and mobile.
- Select questions and replies using checkboxes in the chat area, preview the generated images, and save them with the Aivory logo.
- Paginate long selections into multiple images. Preserve selections after generation errors and provide a readable fallback for interactive content.

## Mobile Camera and Layout

- Include the merged mobile-camera feature for regular and private chats, including a touch-device camera entry and support for large private-chat photos.
- Adapt the formula editor and its controls to touch devices and the visible area above the mobile keyboard.
- Share safe visible-viewport geometry across dialogs, drawers, settings, search, and composer suggestions. Keep controls and content reachable on compact screens and in landscape orientation.
- Improve short-screen document and presentation previews, including office files, long text, and preview loading or error states.

## Updates and About

- Compare sandbox source fingerprints during an application update. Keep the currently running sandbox when its source is unchanged; update the bundled runtime and sidecar together when it changes.
- Add sandbox update progress and health checks, with rollback to the previous images and deployment settings if the update fails. Leave disabled or externally managed sandboxes alone.
- Publish sandbox source metadata in container images and retain support for identifying older images through their source revision.
- Fix the About page displaying a hard-coded `beta.12` version. The web About badge now uses the package release version; desktop About continues to prefer the installed application's version. Build identifiers used for web reload detection remain independent.

## Upgrade Notes

Update the API and web frontend together. SQLite and PostgreSQL migrations add message-level model-skill exclusions automatically; existing messages and saved settings remain supported.

To use sandbox-aware updates, refresh the updater container and use the current deployment Compose file. Existing updater containers keep their previous behavior until replaced. This release does not change the sandbox source, so the new updater can retain an already-current sandbox.

The built-in Generative UI prompt updates automatically only when it still matches a shipped default. Administrators who customized that prompt retain their edits and can add the new component instructions manually.

The production frontend build and targeted ESLint checks passed during release preparation. The built About chunk was checked against the package and lockfile versions. No full test suite was rerun; GitHub Actions builds and verifies the tagged installers and container images.
