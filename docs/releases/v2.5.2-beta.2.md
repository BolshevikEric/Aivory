# Aivory v2.5.2-beta.2

Test release covering all six application commits since **v2.5.2-beta.1**. This version introduces composable HTML-like Generative UI, nested components and SVG, complex tables, administrator-selected map providers, and fixes for sharing, formula editing, image attachments, and image-generation timeouts.

## Composable Generative UI

- Generate themed preset components with HTML-like tags. Compose complete layouts or insert components naturally into Markdown paragraphs, headings, lists, quotes, and table cells without a mandatory fence or outer container.
- Add layout, typography, cards, badges, alerts, images, lists, tabs, accordions, steps, timelines, tooltips, metrics, progress indicators, form controls, buttons, charts, calculators, and function plots. Content components support recursive composition while retaining their semantic structure.
- Share local state between controls and expressions in the same UI group. Buttons and forms can submit follow-up messages with validation, retry feedback, and duplicate-submission guards. Preserve streaming, read-only, and historical-message restrictions.
- Render nested SVG drawings with paths, shapes, text, gradients, clipping, markers, filters, and isolated local definitions. Keep SVG references scoped to each drawing and reject scripts, arbitrary handlers, and foreign HTML.
- Support complex tables with merged rows and columns, multiple header and body groups, footers, unequal column widths, and nested components. Flat tables retain optional sorting and filtering; merged tables preserve their original structure.
- Update the built-in skill and all five localized presentation contracts to teach canonical component tags. Retain legacy structured UI parsing for existing conversations without advertising the old output format in prompts. Upgrade untouched built-in skill defaults while preserving administrator edits.

## Maps and Administrator Settings

- Add the canonical `map` component with `map-point` children. Accept verified coordinates or specific addresses, fit the viewport to located places, and provide numbered markers, zoom and fit controls, place selection, and external place links.
- Allow cards, tables, tabs, forms, images, buttons, and SVG inside selected-place details. Address lookup failures remain visible without inventing coordinates.
- Add **Admin > Tools > Maps** to choose between the default keyless OpenStreetMap/Photon service and **AMap**. The selected provider handles both address lookup and map rendering.
- For AMap, configure the Web Service key, JavaScript API key, and security code in the administrator panel. Keep the Web Service key and security code server-side and use the built-in SDK proxy. Support geocoding with POI fallback and coordinate conversion at provider boundaries.
- Isolate lookup caches by provider and credentials, bound public lookup traffic, and provide loading, configuration, lookup, tile, and SDK recovery states. AMap failures do not silently switch to the other provider.

## Sharing and Exports

- Remove JSON from the conversation's Share submenu and file-format selector. JSON conversation export remains available from the sidebar's Export action.
- Replace native sharing format and image-quality dropdowns with themed custom controls. Escape closes an open dropdown before leaving message selection.
- Preserve nested components, SVG definitions, complex table spans, and column proportions in image and PDF exports. Fit wide tables to the export page and show static place names and links instead of an unmounted map loader.
- Retain PNG, PDF, and TXT previews and downloads, message selections after failed generation, cached exports, and account isolation.

## Composer and Image Reliability

- Fix formula insertion while an image is uploading. Keep keyboard focus in the formula editor, preserve the draft when upload finishes, and restore composer focus after closing the editor on desktop and mobile.
- Preserve existing image attachments when editing and resending a user message into a sibling branch. Validate the original message and attachment ownership on the server.
- Apply the administrator's image-model timeout consistently to direct drawing and chat image tools, including normal, fast, automation, and research paths. Pause the tool-time budget during image generation and remove the old fixed tool timeout and response-header timeout from image requests. Parent cancellation and generation deadlines still apply.

## Upgrade and Compatibility

- Update the API and frontend together to use the new map endpoints and administrator settings. No new database migration is required.
- OpenStreetMap/Photon remains the default and requires no API key. AMap is optional and must be configured by an administrator before selecting it.
- `AIVORY_LLM_TOOL_TIMEOUTS_3` is retired. Configure `image_timeout_sec` on the image model in the administrator panel; `0` adds no model-specific timeout while retaining parent cancellation and deadlines.
- Desktop installers bundle the updated frontend locally, ask for a server address on first launch, and retain saved server settings on upgrade.
- This is a prerelease. The latest stable release remains **v2.5.1**.

## Validation

The application changes passed 127 focused frontend tests, TypeScript checking, scoped ESLint, targeted map and administrator API tests, and the store and LLM package suites. The production frontend build passed with a 4 GB Node heap. Browser assertions cover formula insertion during upload, recursive component composition, SVG and complex tables, interleaved Markdown, map controls and administrator configuration, and PNG/PDF/TXT sharing across desktop and mobile layouts. AMap SDK tests use synthetic places and a mocked SDK; live AMap credentials were not used. Two browser runners completed their assertions but required termination after their cleanup stalled. This does not claim a clean full application test suite or live vendor validation.

Release preparation verifies version and lockfile consistency, the complete commit range, and workflow configuration. CI builds the tagged source, verifies desktop bundles and signatures, and publishes release artifacts.
