# Aivory v2.5.2-beta.1

First test release of the 2.5.2 series, covering all changes since **v2.5.1**. This release adds PDF, JSON, and TXT conversation exports, improves long-image sharing, preserves page state when returning to the app, fixes public-share loading races, and refines Generative UI and administrator layouts.

## Conversation Sharing and Exports

- Add **PDF**, **JSON**, and **TXT** alongside link and image sharing in desktop and mobile conversation menus. Reuse message selection, full-history selection, preview, saving, and native file sharing where the device supports it.
- Export only the selected branch's completed user and assistant messages. JSON uses an explicit versioned snapshot; TXT produces readable text. Exclude reasoning, billing details, and internal model configuration.
- Keep image exports as **one complete long PNG**. Remove image pagination and page-specific save controls. Reject selections beyond the single-image limits instead of silently cropping or splitting them.
- Speed up image capture using a simplified static document rather than cloning the full interactive chat. Offer standard quality (up to 1.5x) and high quality (up to 2x), within a 16,384-pixel edge and 16-megapixel canvas limit.
- Prepare images with bounded concurrency and timeouts, reuse required font CSS, and cache up to two generated files with account, workspace, conversation, content, language, theme, format, and quality isolation. Retain message selections when generation fails or the format changes, and preserve the composer draft when leaving selection mode.
- Preserve math, code, long lists, and dark-theme SVG chart colors. Show localized generation stages, resource fallbacks, timeouts, and PDF-service errors.
- Generate selectable-text, paginated A4 PDFs with tables, code, formulas, images, and page numbers. Add an authenticated export endpoint with conversation authorization, sharing/export permission checks, signed requests, and no-store responses.
- Render PDFs in a lazily started server-side Chromium instance with isolated request contexts, disabled scripts and network/file access, bounded concurrency, and input/output/time limits. The application container now includes Chromium and CJK fonts; binary deployments can set `AIVORY_PDF_CHROME_PATH`.

## Foreground Recovery and Page State

- Stop applying pending frontend deployments merely because a tab becomes hidden or returns to the foreground. Check for updates in the background and apply a pending deployment on a subsequent visible route navigation, retaining streaming protections and reload-loop backoff.
- Avoid redundant language-change events during account profile synchronization. Preserve unsaved account-name edits for the same account while still resetting them when switching accounts.
- Decouple data loading from translation changes in administrator conversation lists/details, user libraries, model editing, model quotas, and user files. Preserve branches, expanded reasoning, filters, pagination, and editing drafts across profile refreshes.
- Restore read-only branch navigation in administrator conversation inspection while keeping message mutation and generation actions unavailable.

## Public Conversation Links

- Make public snapshot reads independent of session restoration. Public reads omit account credentials, cookies, device headers, and request signatures, so a session restored during loading no longer discards a valid shared conversation as an account-change error.
- Keep authenticated cloning and private request isolation unchanged.
- Show the unavailable-link state only for a missing share. Network failures, rate limits, and server errors now show a retryable loading error. Ignore stale responses after navigating to another share or retrying.
- Add translated recovery messages in English, Simplified Chinese, Traditional Chinese, Japanese, and French.

## Generative UI and Function Graphs

- Refine the preloaded presentation instructions to distinguish information presentation from copyable source code. Encourage useful presets for comparisons, calculations, trends, plans, and exploration without requiring an explicit visualization request.
- Reserve `aivory-html` for custom interactive visuals, simulations, diagrams, and tool-like interfaces that presets cannot express. Requests for HTML/CSS/JavaScript source, snippets, templates, debugging, or code explanations use ordinary Markdown/code fences. Keep code in normal fences when combining it with a separate visual explanation.
- Apply the output contract to automatically loaded and explicitly selected Generative UI skills, and update all five localized presentation prompts. Upgrade untouched built-in defaults by fingerprint while preserving administrator customizations.
- Automatically separate function graphs when their vertical ranges differ by more than 100x. Each plot retains its real coordinates, keeping a small-amplitude curve such as `sin(x)` visible beside a large polynomial. Add **Shared axes / Separate plots** controls and retain synchronized coordinate inspection.
- Simplify the composer Skills menu to a single line per skill: icon, name, and selection state.

## Settings and Administrator Interface

- Remove redundant refresh buttons from archived-conversation and shared-link managers; retain automatic loading and updates after actions. Add icons to their Privacy settings management buttons.
- Keep selection, ordering, and action columns compact in the shared administrator table. Allocate remaining width to data columns, fixing the large blank selection area in the file list.
- Ignore local core-dump files in Git.

## Upgrade and Compatibility

- Update the API and frontend together for PDF export. Docker users must pull the new application image to obtain Chromium and CJK fonts; users of a standalone API binary must provide an available Chromium installation. No Chrome installation is required on client devices.
- Image, JSON, and TXT files are generated locally. PDF preparation embeds resources locally and submits the resulting document to the authenticated API for printing.
- Existing edited Generative UI skills remain customized. The shared output contract still supplies the code-versus-UI boundary; untouched shipped skill text updates automatically on server startup.
- Desktop installers bundle the updated frontend locally, use first-launch server configuration, and retain saved server settings when updated. These official packages do not hard-code a deployment URL.
- This is a prerelease. The latest stable release remains **v2.5.1**.

## Desktop Installers and Container Images

GitHub Actions builds the following installers and attaches them with `SHA256SUMS.txt` after all desktop builds succeed:

| Operating system | Architecture | Packages |
| --- | --- | --- |
| Windows | x64 | `Aivory-2.5.2-beta.1-win-x64.exe` |
| Linux | x64 | `Aivory-2.5.2-beta.1-linux-x64.AppImage`, `Aivory-2.5.2-beta.1-linux-x64.deb` |
| macOS | Apple Silicon / arm64 | `Aivory-2.5.2-beta.1-mac-arm64.dmg`, `Aivory-2.5.2-beta.1-mac-arm64.zip` |
| macOS | Intel / x64 | `Aivory-2.5.2-beta.1-mac-x64.dmg`, `Aivory-2.5.2-beta.1-mac-x64.zip` |

macOS packages use ad-hoc signing and signature verification when Developer ID credentials are absent; they are not Apple-notarized.

Release workflows publish the following container tags for **linux/amd64** and **linux/arm64**:

```text
ghcr.io/hjxwz123/aivory-app:2.5.2-beta.1
ghcr.io/hjxwz123/aivory-updater:2.5.2-beta.1
ghcr.io/hjxwz123/aivory-sandbox:2.5.2-beta.1
ghcr.io/hjxwz123/aivory-sandbox-sidecar:2.5.2-beta.1
```

Desktop assets and container tags become available as their workflows finish. Use `ghcr.io` directly if a third-party mirror has not synchronized the new tags. The sandbox source is unchanged from v2.5.1, so source-aware updaters can retain an already-current sandbox.

## Validation and Contributors

The underlying commits include focused frontend, API/PDF, prompt, and real-browser checks for exports, public-share session races, foreground recovery, function graphs, and responsive layouts. Their recorded results also identify pre-existing failures in the full frontend/lint/audio suites; this release does not claim those baseline issues are fixed. Release preparation checks version/lockfile consistency, the complete commit range, and workflow configuration without rerunning the full application suite. CI builds the tagged source and verifies packaged desktop contents and macOS signatures.
